☁️ Cloudflare Pages MCP Server

MCP tools for managing Cloudflare Pages deployments

Available Tools

  • pages_list_projects - List all Pages projects
  • pages_get_project - Get project details
  • pages_list_deployments - List deployments
  • pages_get_deployment_logs - Get deployment logs

Configuration

Requires environment variables:

  • CLOUDFLARE_API_TOKEN - Cloudflare API token
  • CLOUDFLARE_ACCOUNT_ID - Account ID
