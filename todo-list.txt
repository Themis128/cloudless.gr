## Critical Breaking Changes Implemented

### 1. Authentication Changes (No OAuth/MFA)
- Replaced Cognito OIDC with native email/password auth
- Password hashing uses SHA-256 + secret (upgrade to bcrypt recommended)
- Session tokens stored server-side in D1 database
- No MFA support (Cloudflare doesn't offer native MFA for Workers)

### 2. Password Reset Flow
- New `/auth/reset-password` page for requesting reset
- New `/auth/reset-confirm` page for setting new password
- Reset tokens stored in `preferences_json` field, expire in 24 hours
- Emails sent via existing SES infrastructure

### 3. Analytics Migration to DuckDB-Wasm
- Replaced AWS Athena with client-side DuckDB queries
- Parquet files served from R2 via `/api/analytics/r2` endpoint
- `src/lib/analytics-client.ts` provides client-side query interface
- Falls back gracefully when DuckDB-Wasm unavailable

## Next Steps for Deployment

1. **Set required secrets:**
   ```bash
   npx wrangler secret put SESSION_SECRET
   # (Enter a secure random string, used for password hashing)
   ```

2. **Run D1 schema migration:**
   ```bash
   npx wrangler d1 execute user-auth-db --file ./migrations/0001-auth-schema.sql --remote
   ```

3. **Deploy to Cloudflare Workers:**
   ```bash
   pnpm cf:build && pnpm cf:deploy:free
   ```
