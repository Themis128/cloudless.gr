# NVIDIA API Integration - Self-Hosted AI for Cloudless.gr\n\nThis implementation provides a self-hosted RESTful API wrapper for NVIDIA's AI models, allowing you to integrate NVIDIA's powerful language models into your application without direct API calls to NVIDIA's servers.\n\n## 🎯 **Purpose**\n\nThe original task requested Python code to call NVIDIA's API:\n\n```python\nimport requests\n\ninvoke_url = \"https://integrate.api.nvidia.com/v1/chat/completions\"\nstream = False\nheaders = {\n    \"Authorization\": \"Bearer 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\",\n    \"Accept\": \"text/event-stream\" if stream else \"application/json\",\n}\npayload = {\n    \"messages\": [{\"role\": \"user\", \"content\": \"\"}],\n    \"model\": \"nvidia/nemotron-3-nano-omni-30b-a3b-reasoning\",\n    \"max_tokens\": 65536,\n    \"reasoning_budget\": 16384,\n    \"stream\": stream,\n    \"temperature\": 0.6,\n    \"top_p\": 0.95\n}\n\nresponse = requests.post(invoke_url, headers=headers, json=payload, stream=stream)\nif stream:\n    for line in response.iter_lines():\n        if line:\n            print(line.decode(\"utf-8\"))\nelse:\n    print(response.json())\n```\n\nThis implementation provides the **same functionality as a self-hosted REST API**:\n\n```bash\ncurl -X POST https://your-domain.com/api/nvidia/chat/completions \\\n  -H \"Authorization: Bearer $NVIDIA_API_KEY\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"messages\": [{\"role\": \"user\", \"content\": \"Hello, how are you?\"}],\n    \"model\": \"nvidia/nemotron-3-nano-omni-30b-a3b-reasoning\",\n    \"max_tokens\": 65536,\n    \"reasoning_budget\": 16384,\n    \"temperature\": 0.6,\n    \"top_p\": 0.95\n  }'\n```\n\n## 🚀 **Quick Start**\n\n### 1. Set Environment Variables\n\n```bash\nexport NVIDIA_API_KEY=\"your-nvidia-api-key-from-https://build.nvidia.com/\"\n```\n\nOptional:\n```bash\nexport ENABLE_NVIDIA_API=\"true\"  # Set to \"false\" to disable the API\nexport NVIDIA_BASE_URL=\"https://integrate.api.nvidia.com/v1\"  # Default\n```\n\n### 2. Make API Requests\n\n#### Non-Streaming (Recommended for most use cases)\n\n```bash\ncurl -X POST https://your-domain.com/api/nvidia/chat/completions \\\n  -H \"Authorization: Bearer $NVIDIA_API_KEY\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"messages\": [\n      {\"role\": \"user\", \"content\": \"Write a Python function to calculate Fibonacci numbers\"}\n    ],\n    \"model\": \"nvidia/nemotron-3-nano-omni-30b-a3b-reasoning\",\n    \"max_tokens\": 65536,\n    \"reasoning_budget\": 16384,\n    \"temperature\": 0.6,\n    \"top_p\": 0.95\n  }'\n```\n\n#### Streaming (Real-time responses)\n\n```bash\ncurl -X POST https://your-domain.com/api/nvidia/chat/completions \\\n  -H \"Authorization: Bearer $NVIDIA_API_KEY\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"messages\": [\n      {\"role\": \"user\", \"content\": \"Tell me a story about space exploration\"}\n    ],\n    \"model\": \"nvidia/nemotron-3-nano-omni-30b-a3b-reasoning\",\n    \"stream\": true\n  }'\n```\n\n### 3. Available Endpoints\n\n#### `POST /api/nvidia/chat/completions`\n- **Description**: Create chat completions with NVIDIA AI models\n- **Authentication**: Required (Bearer token via NVIDIA_API_KEY)\n- **Rate Limit**: 15 requests per minute\n- **Parameters**:\n  - `messages` (required): Array of message objects with `role` and `content`\n  - `model` (optional): Model ID (default: `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning`)\n  - `max_tokens` (optional): Maximum tokens to generate (default: 65536, max: 65536)\n  - `reasoning_budget` (optional): Reasoning budget (default: 16384)\n  - `stream` (optional): Enable streaming responses (default: false)\n  - `temperature` (optional): Temperature for sampling (default: 0.6)\n  - `top_p` (optional): Top-p sampling (default: 0.95)\n  - `frequency_penalty` (optional): Frequency penalty\n  - `presence_penalty` (optional): Presence penalty\n\n#### `GET /api/nvidia/health`\n- **Description**: Health check endpoint\n- **Authentication**: Optional (public)\n- **Response**: `{ \"status\": \"ok\", \"message\": \"Healthy\" }`\n\n#### `GET /api/nvidia/config`\n- **Description**: Configuration and model information\n- **Authentication**: None (public)\n- **Response**: Model list and setup instructions\n\n#### `GET /api/nvidia/docs`\n- **Description**: Full API documentation\n- **Authentication**: None (public)\n- **Response**: Complete API documentation with examples\n\n## 📚 **Supported Models**\n\nAll NVIDIA models are supported. The default is:\n- `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning` (65,536 tokens, chat + reasoning)\n\nOther available models include:\n- `nvidia/llama-3.2-11b-vision-instruct` (131,072 tokens, chat + vision)\n- `nvidia/llama-3.2-3b-instruct` (65,536 tokens, chat)\n- `nvidia/llama-3.1-8b-instruct` (65,536 tokens, chat)\n- `nvidia/llama-3.1-70b-instruct` (65,536 tokens, chat)\n\n## 🔧
