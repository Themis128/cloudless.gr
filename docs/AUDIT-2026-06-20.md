## 3. Improvements — ranked by (safety × impact)

### P0 — ship now, zero behaviour change (≤ 1 hour each)

1. **Clear the 3 lint warnings.** Either delete the unused exports
   `searchPosts` in `src/lib/notion-blog.ts:247` and
   `getProductsByCategoryAsync` in `src/lib/store-products.ts:99`, or prefix
   with `_` per the eslint rule. Sub-15-min, no behaviour change.

2. **Patch the patch-version dep wave.** `stripe` 22.2.1→22.2.2,
   `@aws-sdk/*` 3.1068→3.1073, `@sentry/nextjs` 10.58→10.59,
   `lucide-react` 1.18→1.21. All semver-patch / minor. Run
   `pnpm up stripe @aws-sdk/client-bedrock-runtime @aws-sdk/client-cognito-identity-provider @aws-sdk/client-dynamodb @aws-sdk/client-iam @aws-sdk/client-s3 @aws-sdk/client-sesv2 @aws-sdk/client-ssm @sentry/nextjs lucide-react` then `pnpm test:ci`.

3. **Replace deprecated `@react-email/components`.** Bumped to deprecated
   status. Pin to its successor (the project's email skill in
   `anthropic-skills:aws-ses-nextjs` covers SES patterns the repo already
   uses) — or freeze on the last known good and document the freeze in
   `CLAUDE.md` so Dependabot stops nagging.

### P1 — quick wins documented in your own docs (1–6 hours total)

4. **Run the Lighthouse 5 quick wins** (`docs/lighthouse-quick-checklist.md`).
   Documented but not yet shipped: defer store code from `/services` (+280 ms),
   fix locale redirect chain (+280 ms), compress `ProductIcon` SVGs (+200 ms),
   defer `TerminalBlock` / `StatCounter` (+250 ms), WebP icon assets (+150 ms).
   Total: **+1.16 s LCP / +18 Lighthouse points / 5.5 h**.

5. **Fix the `/sitemap.xml` 1.75 s response time.** Three calls in this
   audit: `/` 603 ms, `/api/health` 630 ms, `/sitemap.xml` 1 754 ms. The
   sitemap is the only outlier. Cache it via `revalidate` (Notion data is
   the slow path) and add `Cache-Control: public, max-age=3600` on the
   response. Affects nothing user-visible; pure performance + SEO win.

6. **Execute the documented AWS cost cuts** (`docs/aws-cost-reduction.md`).
   The doc identifies **35-40% bill cut (~$6-7/mo)** without losing
   functionality: drop the second CloudTrail trail ($2.31), delete
   AWS Config recorder ($0.84), prune unused KMS CMKs ($1+/key/mo), trim
   Secrets Manager entries ($1.20). All are peripheral services that
   serve zero page requests. Net change to the apps: none.

### P2 — codebase debt, batched (half-day to two-day blocks)

7. **Sweep the 343 `console.*` calls.** Many should be Sentry breadcrumbs
   (the scrubber is already in place — `src/lib/sentry-scrub.ts`). Anything
   that's a real error path should `Sentry.captureException`. Anything
   that's a "happy path log" should go through a `log.info(...)` helper
   so log volume can be tuned per environment. CloudWatch ingest cost
   scales linearly.

8. **Type-tighten 52 `any` usages + 93 `eslint-disable`.** Highest leverage
   targets per file:
   - `src/lib/ad-analytics/*` already has explicit interfaces — likely
     few `any`s and worth scoring as a model.
   - Any `any` in route handlers means a type-unsound request boundary;
     swap for `zod`-validated schemas (already on the dep list per
     `package.json`).

9. **Add the SonarCloud-triage skill to the PR CI feedback loop.** The
   skill (`.claude/skills/sonarcloud-triage/SKILL.md`) documents the
   exact fixes for the rules that fire most often (S3699, S3776, S1192,
   S4787) — wire it into the Claude routine that runs on the PR so
   findings are addressed at PR-open time instead of merge-time.

### P3 — security & infra roadmap (the Q2/Q3 items already in your docs)

10. **AWS WAF in front of CloudFront** (`SECURITY_ENHANCEMENTS_ROADMAP.md`
    Phase 1). Rate-limit 2 000 req / 5 min / IP, geo-allowlist, common
    attack patterns. Mitigates the L7 surface CSP can't cover.

11. **Enable AWS X-Ray tracing on the SST Lambda** (Phase 2 in the same
    doc). Single flag in `sst.config.ts` (`tracing: "active"`). Buys
    you cold-start frequency / duration / latency-by-route visibility —
    the existing `serverless-app_main-errors` CloudWatch alarm only
    counts errors, never explains them.

12. **CSP report-only → enforced.** `proxy.ts` ships a full directive set
    today but as `Content-Security-Policy-Report-Only`. You're already
    collecting reports at `/api/csp-report`. Once a week of clean reports
    has accumulated, flip to `Content-Security-Policy`.

13. **CloudFront edge caching for hot static GETs** (Phase 3 in the same
    doc). Currently `cf-cache-status: DYNAMIC` on `/`. The sitemap +
    OG images + product icons could all live behind a cache policy with
    1 h TTL — cuts Lambda invocations 40-60 %.

### P4 — operations cadence (low engineering, high ongoing value)

14. **Extend the Monday CI health routine** (`docs/ci-health-routine.md`)
    to also run `pnpm cluster:doctor`, `scripts/lambda-env-audit.sh`,
    `pnpm audit`, `pnpm outdated`. It's read-only today, can stay
    read-only after the extension — just adds 4 lines to the prompt and
    saves you doing this audit manually next quarter.

15. **Author an `audit-routine` skill.** One canonical entry point that
    runs items 14 + a Lighthouse run + Sentry top-N errors and posts a
    single Block Kit digest to `#deployments`. Becomes the auditable
    history of stack health over time. Skeleton fits in
    `skills/audit-routine/SKILL.md`.
