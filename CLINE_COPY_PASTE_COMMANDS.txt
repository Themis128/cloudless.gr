PERFORMANCE & OPTIMIZATION

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Analyze home page performance:
Analyze the home page load performance and identify bottlenecks. Measure Core Web Vitals (LCP, FID, CLS), capture console logs, and suggest optimizations.

Test API response times:
Check the API endpoint response times for /api/search. Use Playwright to perform GET request, assert response time is under 500ms, and validate JSON response structure.

Find JavaScript errors:
Identify all JavaScript errors across the application. Navigate to each page/feature, capture console errors, get stack traces, and identify error patterns.

Detect memory leaks:
Detect potential memory leaks in the application. Navigate through multiple pages, monitor console for memory warnings, and suggest memory management improvements.

Analyze network performance:
Perform detailed network performance analysis. Capture all network requests, analyze request sizes, check timing, and identify slow resources.

Test login flow:
Test the complete login flow. Navigate to login page, fill email and password fields, click login button, wait for redirect to dashboard, take screenshot, and capture any errors.

Test checkout process:
Automate and test the entire checkout flow. Fill customer information, fill payment details, click submit, verify success message, and check API calls during submission.

Test contact form:
Validate all form inputs on the contact page. Test empty form submission, test invalid email format, test valid submission, verify success notification, and check API request.

Test search functionality:
Generate comprehensive tests for the search feature. Type various search queries, verify results load, check pagination, analyze response time, and identify slow queries.

Test drag and drop:
Test all drag-and-drop interactions. Find draggable elements, drag to target locations, verify drop behavior, test animation smoothness, and check for glitches.

Test all API endpoints:
Test all API endpoints (GET, POST, PATCH, DELETE). Validate response schemas, test create operations, test updates, test deletions, check status codes, and validate response times.

Test error handling:
Validate error handling for all API endpoints. Test invalid request body, test missing authentication, test missing required fields, verify error messages, and check status codes.

Test rate limiting:
Verify rate limiting is working. Send rapid GET requests to /api/search, capture 429 responses, check rate-limit headers, verify retry-after header.

Test data validation:
Test API data validation. Send requests with missing fields, send requests with invalid types, send oversized data, and verify validation error messages.
