### Pattern Analysis

Tests that use `makeAdminToken()`/`makeUserToken()` with `jwtVerify` mock (like admin-ab-tests-api.test.ts) work differently - they mock the jose library directly. The issue is that the jose mock may not be resolving properly with `vi.importActual`.

Tests that use inline `requireAdminMock.mockResolvedValue({ ok: false, response: { status: 401 } })` fail because `response` needs a `json()` method.
